# BrandBeamer 比赛演示

赛道：效率工具。核心主张：把材料整理、汇报时长分配和机构品牌设置连接成一次连贯的工作流。

## 三分钟演示

1. **0:00–0:20 问题。** 汇报前需要整理材料、控制时长、套用机构模板，这些步骤经常反复进行。
2. **0:20–1:00 生成。** 打开工作台，试用校园循环计划材料，选择 5 分钟并生成。明确当前是规则演示模式，AI 接口可配置。若已经接通真实模型，现场说明实际使用的服务。
3. **1:00–1:40 品牌。** 上传 `public/demo/qinghe-logo.png`，修改机构名称，切换配色，翻页展示全稿更新。
4. **1:40–2:20 编辑。** 选中要点页，修改标题，精简要点，展示讲稿及每页秒数。
5. **2:20–2:50 交付。** 全屏翻页，打开 PDF 打印预览，下载 Beamer ZIP 和可编辑 JSON。
6. **2:50–3:00 开源。** 展示 GitHub、运行命令和多模型接入方式。

## 评分证据

| 评分维度 | 演示证据                                                 |
| -------- | -------------------------------------------------------- |
| 创新性   | 品牌与内容分离、按汇报时长组织内容、网页和专业源码双出口 |
| 应用价值 | 使用真实材料计时，从输入走到导出，不虚报效率提升         |
| 完成度   | 生成、品牌修改、编辑、翻页和文件导出连续完成             |

Logo 上传本身并不是 AI 创新。正式参赛前应在 AI 设置中配置并测试真实模型，用同一份材料展示生成与精简质量，并记录实际耗时。网站模型和个人 API 两种入口均已实现；没有配置密钥时请明确使用演示模式。

## 手动验收

- [ ] 默认示例稿可展示，演示模式有明确标记。
- [ ] 自己的材料生成后反映输入内容，3/5/10 分钟总秒数正确。
- [ ] 中文标题、要点、讲稿实时更新，长内容有密度提示。
- [ ] PNG 和 JPG 上传有效，超过 2 MB 或无效文件有错误提示。
- [ ] 机构名、颜色、Logo 在每页与导出中一致。
- [ ] 页面添加、删除、重排后序号与总秒数正确。
- [ ] 演示支持方向键和 Esc，退出后继续编辑。
- [ ] JSON 下载再导入，内容和 Logo 保留。
- [ ] 刷新后恢复草稿，本地存储不可用时有提示。
- [ ] PDF 每页一张幻灯片，无编辑控件，无额外空白页。
- [ ] Beamer ZIP 可解压，包含主题、源码、说明、许可证和上传 Logo。
- [ ] 缺少 API 密钥时 AI 操作失败但不丢失现有材料与稿件。
- [ ] AI 设置能选择网站模型，或填写 / 导入自己的服务商、接口地址、模型和密钥。
- [ ] 测试连接的失败信息可读，关闭未应用的设置不会更换当前模型。
- [ ] 个人密钥不出现在草稿导出中，刷新页面后需要重新填写。
- [ ] 接入真实模型后核对数字、事实、耗时和输出可读性。

## 备用方案

现场网络异常时切换明确标注的演示模式，继续展示品牌编辑和文件导出；可以导入提前保存的真实 AI 草稿，但必须说明它是预先生成结果。
